# Swagger 链接导入与更新

## 使用方式

在“性能测试 → 压测项目 → 接口库 / 导入”选择链接模式，粘贴 Swagger 页面或 OpenAPI JSON/YAML 地址，获取并预览新增、修改、删除的接口，再确认导入。文件导入继续保留。

例如，来源页面 `https://api.example.test/swagger/#/`，其静态 Swagger 配置指向同一服务的 `/openapi.yaml`。平台只读取页面中的文档地址，不执行远程页面脚本。动态 JavaScript 配置等不能识别的页面需提供直接文档地址。

成功确认后项目保存来源与解析后的文档地址。再次打开项目可点击“检查更新”，无需寻找本地文件。每次检查重新读取服务端文档；文档没有变化时复用原接口库版本。更新需要确认，不自动改写已有场景、执行快照或报告。

## 一致性与访问范围

- 预览与导入绑定当前项目、操作者、来源地址、文档地址、内容摘要和接口库版本。确认前文档或版本变化需要重新预览。
- 来源获取失败不会清空现有接口库；来源随成功确认保存，文件导入后清除原链接来源，避免错误显示文件来自旧网址。
- 部署配置 `PERF_CATALOG_ALLOWED_ORIGINS` 指定可访问的完整 HTTP(S) 来源（协议、主机、端口）；默认未配置时不开放网络导入。例如配置 `https://api.example.test`；增加其他服务须更新部署配置。来源链接不支持内嵌账号密码、Token查询参数或额外认证头。
- 下载有大小及超时限制，禁止通过页面引用跳到其他来源。不启用代理，不执行文档内的脚本，不获取外部 `$ref`。
- 原始 YAML 使用安全解析，支持重复定义锚点时引用最近定义，仍限制循环、结构深度和展开预算。
- YAML 合并键 `<<` 在构造前拒绝，防止合并展开耗尽内存；普通重复锚点和带引号的普通 `"<<"` 属性仍可使用。

当前部署来源使用固定 IP。未来开放域名来源前，应补充 DNS 解析的总体时限；socket 超时并不能完整限制系统 DNS 解析时间。

## 与压测目标的关系

接口库来源用于描述路径与参数。实际压测目标仍由场景环境和请求地址决定；链接导入不绑定业务身份，不发起压测。运行前须检查最终请求地址并完成单用户调试。
