# k6 项目文件请求

接口库配置编辑器可以上传或选择当前项目的 `UPLOAD` 测试文件；场景步骤编辑器使用相同的项目文件列表。文件不接受本地路径或远程下载地址。

- `FORM`：正文为 JSON 对象，值只支持字符串、数字、布尔值。普通字段支持已有变量模板。选了文件后发送真正的 `multipart/form-data`，文件字段名不得与普通字段重名。Content-Type 留空或填 `multipart/form-data`，multipart 边界由 k6 生成。未选文件的 FORM 发送 URL 编码表单。
- `BINARY`：选择一个文件，文本正文为空；该文件字节作为整个请求体，适用于服务端签发上传地址后的 PUT。Content-Type 优先使用步骤配置，否则使用文件媒体类型。既有 URL、鉴权、重定向限制仍然生效，第三方签名地址不能携带业务账号凭据。
- 每步最多 16 个文件，单场景去重后的文件合计不超过 20MB，空文件拒绝。实际发送前必须通过项目归属、文件存在和路径边界检查。

执行创建时冻结内容、大小和 SHA256 到私有执行快照。引擎校验哈希后写入私有运行目录，不再读取可变源文件。删除或替换源文件不改变已创建执行；新验证会重新检查文件，文件变化会使旧接口验证失效。无文件接口的既有验证指纹保持不变。

k6 通过 SharedArray 共享文件编码，只有实际进入文件步骤的 VU 才解码发送。文件内容、文件名、存储路径不进入公开执行摘要。HTTP 上传复用普通请求的断言、提取、超时和统计，也受执行组的参与 VU、最大尝试次数和间隔限制；失败不返还尝试配额。

部署同时应用普通模型迁移 `0020` 或压力配置迁移 `0011`。本地受控接收器测试覆盖 multipart 字节、文件名、普通字段及变量，BINARY 字节，503 的真实失败计数，组配额，以及源文件变化后的快照不变性。这些平台能力测试不代表任何业务接口已经验证通过。

2026-09-20 隔离 Docker 组合验收使用4VU×2轮，成功链完成20次HTTP与4次PUSH会话；multipart503、事件error、保活error和BINARY503均产生预期失败及依赖阻断，失败不返还额度，第二轮受次数上限跳过。接收端核对各身份的实际字节，源文件修改/删除不影响已冻结执行，连接结束归零，公开结果未包含文件内容或凭据。该结果不涵盖1000VU内存预算或业务容量。

## 发布与回滚

发布沿用活动任务检查、冷备、迁移和历史核对；新增文件字段默认空值，不改旧步骤。发布后先核对账号池、原步骤与历史，再正常配置并低量验证文件请求。

回退到0.9或更早版本前，暂停执行入口和调度，确认没有活动任务及残留worker/k6，保存文件与PUSH步骤清单并禁用它们。旧版不能理解文件快照和类型事件协议，禁止重跑这些新快照；仅从已禁用相关步骤的场景新建执行。保留新增字段、私密冻结文件、历史和账号池，不做逆向迁移；恢复0.10后按清单重启步骤并预检。回退0.8或更早版本还须遵守[专项策略回滚限制](bounded-execution.md#发布与回滚)。
